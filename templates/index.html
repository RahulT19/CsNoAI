How the forecast is calculated — four steps
1

Scrape ten sessions

One static quote page per symbol is parsed with BeautifulSoup. The price table is identified from its header labels, then the latest ten data rows are read out cell by cell. Dividend and split rows carry no OHLC data and are skipped.

2

Clean & index

pandas coerces the numbers, drops unusable rows, de-duplicates dates, sorts chronologically, clips to the trailing ten sessions and attaches the regression index t = 1…10.

3

Fit the lines

For the high and low series independently, ordinary least squares minimises Σ(yᵢ − ŷᵢ)² for ŷ = m·x + c. Both lines are evaluated one step past the window at t = 11.

m = ( n·Σxy − Σx·Σy ) / ( n·Σx² − (Σx)² )
c = ȳ − m·x̄        R² = 1 − SS_res / SS_tot
4

Decide

Upside and downside are measured against today’s close. The first matching rule wins, so a breach of the drawdown boundary always overrides a tempting upside.

SELL  if downside ≥ {{ '%.1f'|format(thresholds.downside) }}%  or  slope(high) < 0
BUY   if upside   ≥ {{ '%.1f'|format(thresholds.upside) }}%  and R² > {{ '%.2f'|format(thresholds.r2) }}
HOLD  otherwise

Full derivation, the decision table and the failure modes live on the methodology page.
